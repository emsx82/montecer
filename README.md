# Municipio de Changuinola – Sitio web educativo

Estructura:
municipio-changuinola/
├── index.html
├── css/styles.css
├── js/script.js
└── img/ (portada, historia, turismo, cultura, economia .jpg)

Ejecutar: abrir index.html con doble clic en Chrome, Edge o Firefox (no requiere servidor).
Opcional: `python -m http.server 8000` dentro de la carpeta y abrir http://localhost:8000
Imágenes: las incluidas son marcadores de posición; reemplácelas por fotos reales con el mismo nombre.
